## 1. 当前主线结论

当前主线已经固定为：

- 角色：`IRONCLAD`
- 训练方式：`hybrid`，`pipe-binary`，`multi_process = true`
- 环境数：`4 env`
- 每轮采样：`episodes_per_iter = 160`
- 主线策略：`no-MCTS`
- 节奏：`save-interval = 5`

当前最重要的判断：

1. 多进程 worker 权重同步已经修好，训练现在是可信的。
2. `Act1 no-elite + 路线规划 + boss 条件化卡奖 + combat safety rerank` 能稳定把更多局送到 boss。
3. 当前仍然没有稳定通关，主瓶颈仍然是：
   - build coherence 不够
   - boss-ready 构筑不够
   - `combat_pending_stall` 仍有污染

   - `Act1 boss -> Act2` 过渡曾经会过早落到 map，导致没有正确体现回血/后续结算
   - 该修复已经落代码，但需要下一次重启 host / 训练后才会真正生效

### 2.2 当前主线的关键在线策略

#### 非战斗

- 非战斗仍然以逐屏 PPO 为主。
- Act1 地图选择已经不是纯 PPO：
  - 先做 `Act1` 路线规划
  - 路线规划已经从“只避 elite”升级成：
    - 避开强制 elite
    - 优先 shop / rest
    - 结合后续节点价值打分
- 商店现在有一个明确硬规则：
  - 只要能删牌，优先删牌
  - 删牌优先级：`STRIKE_IRONCLAD -> DEFEND_IRONCLAD -> BASH`
- 卡奖现在有 boss 条件化 rerank：
  - 至少区分 `Soul Fysh` 和 `Waterfall Giant`
  - 结合 `skada boss_best_cards` 和手写 prefer / avoid

#### 战斗

- 战斗仍以 combat PPO 为主。
- 当前已接入 `combat safety rerank`：
  - 在低血 / 高 incoming 的局面，压制明显贪 setup、低即时收益的动作
- `combat_pending` 已经不是单纯盲 `wait`：
  - 现在会先 refresh
  - 再少量 wait
  - 并落更细的 debug 结构化日志

#### collector / worker

- 多进程 collector worker 每个 iter 都会 refresh 最新权重。
- ORT / worker refresh 路径已经修复，不再长期拿启动时旧模型 rollout。

## 6. 当前最重要的问题

### 6.1 build 仍然不够 boss-ready

现象：

- 进 boss 的比例已经不低
- 但 `high_hp_boss_loss` 仍然高
- 说明不是单纯残血进 boss，而是 build 不够成型

### 6.2 shop 资源转化仍然偏弱

现象：

- 已经进 shop
- 也有 remove 硬规则
- 但 `affordable_shop_skip` 仍然高

解释：

- 现在不是“完全不进商店”
- 而是“进商店后资源没有稳定转成更好的 build”

### 6.3 `combat_pending_stall` 仍然有污染

虽然等待逻辑比之前好很多，但：

- `combat_pending_stall_count` 仍不低
- 这部分会继续污染 boss 统计

### 6.4 Act1 -> Act2 过渡曾经有环境 bug

已经确认过的旧问题：

- boss clear 后，有些样本没有正确等到 Act 切换完成
- 过早落到 map / 下一战，导致没有正确体现 Act 结算

当前状态：

- 修复已落在 `STS2AI/ENV/Sim/Overlay/Simulation/FullRunSimulatorRuntimeFacade.cs`
- 但当前正在跑的 host 不会热加载
- 需要下一次重启训练/host 后，结果才会吃到这版修复
