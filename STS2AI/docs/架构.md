## pureSim 状态

### 已经成立的事实

- pureSim 已可用于主线短训练和实验
- pureSim / Godot 基线对齐度已足够实用
- pureSim 存档/读档已基于服务端内存快照

### 尚未成立的事实

- pureSim 还不是"零尾巴永久版"
- 一些低频转换/循环问题仍可能出现
- Godot 仍保留为确认后端

## MCTS 状态

### 不是主线方案

MCTS 当前是预实验路线，不是默认训练路径。

### MCTS 目前的用途

- 仅战斗预实验
- 短前瞻
- 战术排序调研
- 通过 [evaluate_ai.py](STS2AI/Python/evaluate_ai.py) 做根节点诊断

### 当前结论

- MCTS 原则上可以帮助卡牌排序
- 当前瓶颈更多在叶节点目标而非树参数
- 不要把完整 MCTS 当作当前默认架构
