# 铁甲评测协议

本协议保证教师和评分器实验之间具有可比性。

## 固定种子梯度

- 快速 A/B：`20` 个种子
- 稳定性 A/B：`50` 个种子

如果没有种子文件，`evaluate_ai.py` 会回退到确定性种子名
`EVAL_001`、`EVAL_002`，以此类推。这对本协议来说是可接受的。

## 必须指标

- `avg_floor`
- `boss_reach_rate`
- `act1_clear_rate`
- `avg_boss_hp_fraction_dealt`

## 辅助参考指标

- `combat_teacher_override_counts`
- `avg_combat_teacher_overrides_per_game`
- `games_with_combat_teacher_override`

## 教师模式

- `hard_override`
  - 基线优先模式。
  - 教师仅在运行时门控判定基线动作明显可疑时才覆盖。

- `full_replace`
  - 教师优先模式。
  - 战斗动作直接来自教师评分器，只有极少数致命特殊情况例外。

## 推荐当前工作流

1. 用 `hard_override` 在 `20` 个种子上对比教师 checkpoint。
2. 如果某个候选明显更好，用 `50` 个种子重跑。
3. 只有在 `hard_override` 稳定后才对比 `full_replace`。
4. 把没有 `act1_clear_rate > 0` 的 `avg_floor` 提升视为方向性结论，不是最终结论。

## 建议命令

```powershell
powershell -ExecutionPolicy Bypass -File STS2AI/Python/scripts/run-ironclad-teacher-eval.ps1 `

  -Mode hard_override `
  -SeedCount 20
```
