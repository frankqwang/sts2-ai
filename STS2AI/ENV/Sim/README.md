# HeadlessSim 边界

`STS2AI/ENV/Sim` 是 AI 训练使用的独立 full-run simulator 工作区。

当前目录：
- `HeadlessSim/`：主 simulator 项目、运行入口、simulation/training/test support 代码
- `SrcCompat/`：源码级 compat 覆盖，以及提交入库的 auto-generated headless-safe compat 文件
- `GodotSharpStub/`：HeadlessSim 编译所需的最小 Godot / 外围类型 stub
- `scripts/`：当前仍在使用的扫描、compat 生成、stub 生成脚本

当前主链脚本：
- `scan_headless_ui_risks.py`：按 `HeadlessSim.csproj` 实际编译边界扫描 headless UI 风险
- `generate_headless_model_compats.py`：根据风险报告批量生成 `SrcCompat/AutoGenerated`
- `stub_generator.py`：按当前编译边界重建 `HeadlessSim/GeneratedStubs.cs`

这里应该放：
- `HeadlessSim/` 下的核心 simulation runtime、DTO、training bridge
- `FullRunTrainingEnvService` 所需的纯逻辑 manager / model
- 序列化必需的最小 null-platform save schema 类型
- 被排除的 Godot / UI 符号对应的稳定 compat shim
- 提交入库、在 compat 覆盖变化时刷新的 `SrcCompat/AutoGenerated/`

这里不该放：
- 本地调试产物和一次性 build 日志
- 已不参与构建的 UI reflection helper
- 试图重建完整 gameplay / UI 行为的 stub
- 历史自动修补脚本链路和旧目录时代的残留文件

stub 约束：
- stub 只负责满足编译边界
- stub 可以提供类型壳、静态工厂、平凡属性
- stub 不能承载真实选择、UI 或 gameplay 语义
- 新依赖优先通过收紧编译输入和新增 `SrcCompat` 处理，不优先扩张 stub
